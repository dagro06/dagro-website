Setup

1. GitHub Personal Access Token

Nodig om wijzigingen op te slaan. Maak een token aan op github.com/settings/tokens.

  • Ga naar GitHub Settings → Developer Settings → Personal Access Tokens → Fine-grained tokens
  • Klik "Generate new token"
  • Geef het een naam (bv. "Dagro Admin")
  • Selecteer alleen de repository dagro-website
  • Onder "Repository permissions", zet Contents op Read and write
  • Klik "Generate token" en plak het hieronder

    3. Notion Integratie (voor Blog & Cases)

    De Notion API key kan op twee manieren worden ingesteld:

  • Optie A (aanbevolen): Stel NOTION_API_KEY in als environment variable in je Vercel Dashboard → Settings → Environment Variables
  • Optie B: Vul de API key hieronder in (wordt dan via de browser meegestuurd)

    • Deel je Notion databases met de integratie via het "..." menu → Connections.
